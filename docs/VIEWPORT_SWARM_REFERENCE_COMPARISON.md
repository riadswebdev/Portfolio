# Viewport Swarm Reference Comparison

Research and implementation status: 2026-11-10. This comparison separates local browser observations from published source and store-listing claims. The target is the construction choreography of the live Original Swarm, not its current marketing-page design.

## Deliberate differences from the references

- The Original Swarm bundle's light marketing design and page copy are not copied. Its current live site is a product landing page; the transferred requirement is its observable cursor choreography.
- Swarm Rebuild's README describes top-down scroll gates. This portfolio instead finishes only the visible viewport and waits for scroll before admitting lower-page work.
- Worker cursors stay simple arrows without halos or extra tool silhouettes. Temporary selection rectangles and text carets appear only while their corresponding real target is being worked.
- No source code was copied from any reference. No license permitting reuse was established for Original Swarm or Swarm Rebuild.
